EXPERT: We introduced an LLM‑as‑a‑Judge evaluation framework that measures SQL Query Generation Error Rate, faithfulness to the source data, and answer relevance. By tracking those metrics, we could systematically improve prompt quality and reduce errors.

HOST: You also built a document‑update tracking service for that bot. Why was that needed?
EXPERT: The knowledge base needs to stay current. The tracking service watches for updates to source documents, re‑indexes them, and refreshes the vector store. We also added key‑value caching to speed up retrieval and generation.
