PDF to Podcast
==============

Run these commands from the project folder in Command Prompt. Install
dependencies once:

    .venv\Scripts\activate
    python -m pip install -r requirements.txt

Set up .env
-----------

Copy .env.example to .env and add the API key for the LLM provider you want to
use. Model defaults are in .env; use --model MODEL_NAME to override one.

Create a podcast script and audio from a digital-text PDF
---------------------------------------------------------

Put the PDF in input/, then run:

    python main.py GenAiDigitalQuestions.pdf --provider groq

Choose --provider groq, gemini, or openai. Generated files are saved as
output\<PDF name>_podcast.md and output\<PDF name>_podcast.mp3. Add
--overwrite if those files already exist.

Generate audio from a script you already have
---------------------------------------------

Use this command for the default Edge voices (Indian English):

    python make_mp3.py "output\GenAiDigitalQuestions_podcast.md" "output\GenAiDigitalQuestions_podcast.mp3"

To use Gemini TTS instead, set GEMINI_API_KEY in the project .env first, then
run this command. make_mp3.py loads the key from .env automatically:

    python make_mp3.py "output\GenAiDigitalQuestions_podcast.md" "output\GenAiDigitalQuestions_podcast.mp3" --tts-provider gemini

Gemini uses Kore and Puck with Indian English accent guidance. It requires
access to the configured Gemini TTS model and may incur charges. The model
defaults to GEMINI_TTS_MODEL in .env, or gemini-3.8-flash-tts if unset.
Override it for one run with:

    python make_mp3.py "output\GenAiDigitalQuestions_podcast.md" "output\GenAiDigitalQuestions_podcast.mp3" --tts-provider gemini --tts-model gemini-3.8-flash-tts

The script must contain two labeled speakers, such as HOST: and EXPERT:.
Gemini sends their turns together to make a continuous multi-speaker
conversation. Edge synthesizes each turn separately. If an output MP3 already
exists, FFmpeg replaces it.

Optional audio settings
-----------------------

Edge voices default to Indian English male Prabhat for speaker one and female
Neerja for speaker two. Change them with:

    python make_mp3.py "output\podcast.md" "output\podcast.mp3" --speaker-1-voice en-IN-PrabhatNeural --speaker-2-voice en-IN-NeerjaNeural

Adjust Edge speech speed (Gemini uses its own pacing):

    python make_mp3.py "output\podcast.md" "output\podcast.mp3" --rate +10%

Run:

    python make_mp3.py --help
    python main.py --help

Requirements and limitations
----------------------------

FFmpeg must be installed and available on PATH. Gemini audio generation
requires GEMINI_API_KEY in .env. The PDF workflow extracts selectable text
with pypdf; scanned/image-only and handwritten PDFs are not supported.
